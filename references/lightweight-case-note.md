# Lightweight Case Note

This case is only a reminder of the workflow shape, not a persona template.

## What Mattered

- Start from the user's real photos and corrections.
- Preserve a few recognizable face, hair, expression, and posture anchors.
- Keep the visual style quiet enough that the person remains the focus.
- Treat user feedback as reusable rules, not one-off edits.
- Separate real-photo wardrobe references from clothing extracted from successful generated variants.

## What Not To Copy

Do not copy this case's biography, props, outfits, job context, or scene set. New user inputs always define the new character.
